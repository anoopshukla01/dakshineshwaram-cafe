# Dakshineshwaram Café (दक्षिणेश्वरम कैफे)

Official mobile-first Link-Hub landing page for **Dakshineshwaram Café**, an authentic South Indian restaurant in Gorakhpur.

> *"Simple Grains. Divine Flavours."*

---

## 🌟 Features

- **Mobile-First Link Hub**: 2-column action grid with direct links to Swiggy, Zomato, WhatsApp, Google Maps, Website, and Google Reviews.
- **Traditional South Indian Aesthetic**: Warm roasted coffee leather palette with glowing temple gold accents, Devanagari calligraphy, and green Sikku Kolam motif.
- **Interactive Micro-Animations**:
  - Live flickering flame glow on hanging brass diya lamps.
  - Smooth hover lifts and gold glow on action buttons.
  - Staggered entrance animations.
  - Click tracking hook in `script.js` for analytics integration.
- **Pure Web Stack**: Built with semantic HTML5, modern CSS3, and vanilla JavaScript (no frameworks or external dependencies).
- **Fully Responsive**: Optimized for all viewports from 360px mobile screens to large desktop monitors.

---

## 🚀 Quick Start

Simply open `index.html` in any web browser, or run a local HTTP server:

```bash
# Using Python
python3 -m http.server 3000

# Open in browser
open http://localhost:3000
```
